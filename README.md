# High-Precision PM Compliance Screener

> A roadside monitoring service using Point Sampling (PS) technology to identify high-emitting vehicles, specifically targeting the most significant contributors to urban particulate matter. The system focuses on high-precision detection of PM2.5 to isolate 'super-emitters' that bypass standard sensors.
